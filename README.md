A single one-line warning label for a time machine, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> WARNING: You have already ignored this label. That is how you got here.

## Why this line

- **A real warning label:** regulation voice, WARNING in capitals, phrased like a genuine safety notice — the joke cuts against the official calm.
- **A real hazard, turned:** the danger is the traveller's own loop — the label only gets read after it has already been disobeyed.
- **Surprise saved for the end:** "That is how you got here" lands in the last words, where the reader least expects it.
- **Fresh:** the field saturates with do-not-meet-yourself and grandfather/butterfly variants; a self-referential label is untouched.
- **Tight:** 71 characters against the 120-character gate, every word doing work.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
